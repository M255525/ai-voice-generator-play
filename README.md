# AI 快速語音產生器（純瀏覽器版）

打開網頁就能用的文字轉語音工具：輸入文字或上傳 `.txt`，用你自己的 API 金鑰（Google Gemini／OpenAI／ElevenLabs 官方服務）生成語音並下載；也能生成兩人對話、依 SRT／VTT 字幕時間配音，以及語音轉文字。沒有後端伺服器。

- **單人語音**：試聽、下載；沒有金鑰可用瀏覽器內建朗讀試聽。
- **雙人對話**：「講者：內容」逐行格式，自動偵測 2 位講者。
- **字幕配音**：每句在字幕開始時間念出，空檔補靜音。
- 可加入主畫面（PWA）。

## 語音服務

`tts.js` 只呼叫各家公開的官方 API，金鑰存在使用者的瀏覽器，文字由瀏覽器直接送到服務商。2026-11-25 起停用原本的語音代理（`worker.js` 只剩停用訊息）。
