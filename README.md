# AI 快速語音產生器（純瀏覽器版）

打開網頁就能用的文字轉語音工具——輸入文字或上傳 `.txt`，用線上制式聲音快速生成語音並下載成 mp3；也支援「講者：內容」逐行格式，生成兩人對話語音。**沒有後端伺服器**（除了一個極輕量、只負責轉發配音請求的代理），其餘全部在你的瀏覽器裡完成。

## 線上試玩

打開 `index.html`（或部署後的 GitHub Pages 網址）即可使用，不需要安裝、不需要帳號。

## 功能

- **單人語音**：貼上文字或上傳 `.txt`（自動偵測 UTF-8／Big5 編碼），選聲音與語速，生成後可線上試聽、下載 mp3。
- **雙人對話**：用「講者：內容」逐行格式輸入講稿，自動偵測 2 位講者，分別指定聲音，生成整段對話音檔。
- 6 種中文制式聲音（台灣腔／中國腔各 3 種，男女皆有）。
- 可加入主畫面（PWA），像 App 一樣從桌面/主畫面開啟。

## 架構：為什麼需要一個「代理」

這個工具幾乎整個都在瀏覽器裡完成，**除了配音這一步**。線上語音合成服務會檢查連線來源（`Origin` header），而瀏覽器基於安全設計不允許 JavaScript 偽造這個 header，導致網頁沒辦法直接連上去要配音。`worker.js` 是解法：一個跑在 [Cloudflare Workers](https://workers.cloudflare.com/) 免費方案上的極簡代理，唯一的工作是幫網頁把配音請求轉發出去、把結果原封不動送回來——不儲存任何內容，也不需要資料庫。

### 部署你自己的代理（可選，作者已提供預設代理）

```bash
npm install -g wrangler
wrangler login
cd web
wrangler deploy
```

部署完成後會拿到一個 `https://xxx.workers.dev` 網址，貼到頁面「🔧 語音服務代理網址（進階）」欄位並按儲存即可（設定只存在你的瀏覽器）。也可以直接在頁面「🚀 想擁有自己專屬的配音服務？」面板跟著圖形化步驟操作，不需要安裝任何指令列工具。

## 跟「本機版」的差異

同一個工具還有一個[本機版](../)（需下載到自己電腦、用 Python 執行）。純瀏覽器版不需要安裝，但因為沒有 ffmpeg，雙人對話的句子之間不會插入靜音停頓（直接銜接，靠講者切換時的聲音差異分辨段落）。

## 隱私與使用限制

無資料庫、無登入機制。輸入的文字只會經由代理送到線上語音服務做合成，代理本身不儲存任何內容；生成的音檔只存在瀏覽器記憶體，重新整理頁面就會消失（下載後才會留在你的裝置）。配音為線上制式聲音，非真人聲音克隆。僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
