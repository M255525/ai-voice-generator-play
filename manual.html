AI 快速語音產生器（純瀏覽器版）· 操作手冊

打開網頁就能用，不需要下載安裝。輸入文字直接生成語音，或生成兩人對話語音，並下載成音檔（需要自己的語音服務金鑰）。

快速開始

單人語音：在「🎙️ 單人語音」分頁貼上文字（或上傳 .txt 檔），選一種聲音與語速，按「🎧 產生語音」，幾秒後即可試聽並下載。單次最多 2000 字。

雙人對話：切到「💬 雙人對話」分頁，依「講者：內容」格式逐行輸入對話講稿，例如：

甲：早安，今天想聊聊什麼？
乙：我在想要不要來討論一下這個新專案。
甲：好啊，你先說說看你的想法。

系統會自動偵測講者名稱（必須剛好是 2 位，且每行拼寫要一致），分別指定兩位講者要用的聲音，按「🎧 產生對話語音」即可生成整段對話。

語音服務與金鑰

產生可下載的語音檔，要用你自己的 API 金鑰。在頁面上方「🔑 語音服務」選一家並貼上金鑰，只要設定一次：

服務說明
Google Gemini（預設）在 Google AI Studio 申請金鑰，費用與免費額度以 Google 公告為準；輸出 .wav，不支援調語速。
OpenAI在 OpenAI 平台 申請金鑰，依用量計費；輸出 .mp3。OpenAI 公告 tts-1、tts-1-hd、gpt-4o-mini-tts 預定 2027-01-06 停用。模型填 tts-1 才能調語速。
ElevenLabs在 ElevenLabs 申請金鑰，並貼上語音 ID（一行一個，可寫「旁白=語音ID」）；輸出 .mp3，語速範圍 0.7～1.2 倍。請只使用你有權使用的聲音。

沒有金鑰：「單人語音」可以按「🔈 瀏覽器朗讀」，用電腦或手機內建的語音免費試聽，但不能下載。雙人對話與字幕配音需要金鑰。

金鑰只存在這台電腦的瀏覽器，文字由瀏覽器直接送到你選的服務商，不經過本站伺服器。共用電腦請在用完後清空金鑰欄位。

字幕配音（SRT）

切到「🎬 字幕配音」分頁，上傳 .srt（或 .vtt）字幕檔，也可以直接貼上。每一句會在字幕的開始時間念出來，中間的空檔自動補靜音，做出來的音檔長度跟字幕一致，放進剪輯軟體從 0 秒對齊就能配上影片。

  • 多位講者：字幕開頭寫「名字：」（例如「甲：大家好」），勾選「當成講者」後可以每位講者各選一種聲音，名字本身不會念出來；沒有標名字的句子用預設聲音。
  • 念不完怎麼辦：一句話念的時間比字幕長（會先算到下一句開始前的空檔），系統會用比較快的語速重念一次，最多加快到你選的倍數（預設 1.3 倍）；還是放不下，就等前一句念完再開始。完成後會列出哪幾句被加快、延後，方便回去改字幕或刪字。
  • 對齊後字幕：有句子被延後時，可以按「下載對齊後字幕」，拿到時間改成實際念出來時間的 .srt，跟音檔一起用就會對得上。
  • 目前的語音服務不能調語速時，念太長只會往後順延；句數多時要等一段時間，可以隨時按「停止」。

上傳文字檔

支援 .txt 純文字檔，會自動偵測編碼（UTF-8 或 Big5／cp950 皆可正確讀取中文），不需要自己先轉檔。

語音轉文字

切到「📝 語音轉文字」分頁，選好辨識語言（中文台灣／中文中國／英文），按「🎤 開始錄音」並允許麥克風權限，對著麥克風說話即會即時轉成文字，累加顯示在下方文字框；按「⏹ 停止錄音」結束。文字結果可以直接編輯修正，也可以「📋 複製文字」或「⬇️ 下載 .txt」存檔，或按「🗑 清空」重新開始。

只支援即時錄音，不支援上傳已錄好的音檔轉文字——這是瀏覽器語音辨識功能本身的限制，沒有官方方式可以把音檔餵給它辨識，只能對著麥克風即時說話。如果需要把既有音檔轉成文字稿，目前這個工具無法做到。

這個功能使用瀏覽器內建的語音辨識，建議用 Chrome 或 Edge，Firefox／Safari 大多不支援，開啟後會直接提示不支援。辨識是把錄音送到瀏覽器廠商（如 Google）的雲端伺服器處理，需要網路連線，跟語音生成功能使用的服務是各自獨立的兩件事。

常見問題

Q：生成失敗，顯示連線錯誤怎麼辦？
先看錯誤訊息：金鑰不正確就重新複製貼上；額度用完（429）就稍後再試或檢查帳戶額度；找不到模型（404）就清空「模型」欄位改用預設值，或換一家服務。

Q：雙人對話一直顯示「偵測到 N 位講者」不是 2 位怎麼辦？
請檢查每一行講者名稱拼寫是否完全一致（例如不要有時寫「甲」有時寫「Ａ」），且每行都要用全形或半形冒號分隔講者與內容。

Q：以前不用金鑰就能產生語音，為什麼改了？
原本的免費聲音來自未公開的線上朗讀服務，沒有可確認的使用授權，2026-11-25 起停用，改用各家公開的官方服務。

隱私與使用限制

  • 輸入的文字會由瀏覽器直接送到你選的語音服務（Google Gemini、OpenAI 或 ElevenLabs），內容如何處理請看該公司的條款，請勿輸入個資或機密。
  • 發布語音時，請依各服務商規定讓聽眾知道這是 AI 合成語音。
  • 提及的產品與服務名稱為各權利人之商標，本工具與這些公司沒有隸屬、贊助或授權關係。
  • 語音轉文字會把錄音送到瀏覽器廠商的線上辨識服務（例如 Chrome 送到 Google 伺服器），本工具不會另外儲存錄音或文字內容。
  • 生成的音檔與文字稿只存在你瀏覽器的記憶體裡（下載後才會存到你的裝置），重新整理頁面就會消失。
  • 請勿用來生成足以誤導他人、冒充真實人物、或用於詐騙的內容。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
