AI 快速語音產生器（純瀏覽器版）· 操作手冊

打開網頁就能用，不需要下載安裝、不需要伺服器。輸入文字直接生成語音，或生成兩人對話語音，可下載成 mp3 檔。

快速開始

單人語音：在「🎙️ 單人語音」分頁貼上文字（或上傳 .txt 檔），選一種聲音與語速，按「🎧 產生語音」，幾秒後即可試聽並下載。單次最多 2000 字。

雙人對話：切到「💬 雙人對話」分頁，依「講者：內容」格式逐行輸入對話講稿，例如：

甲：早安，今天想聊聊什麼？
乙：我在想要不要來討論一下這個新專案。
甲：好啊，你先說說看你的想法。

系統會自動偵測講者名稱（必須剛好是 2 位，且每行拼寫要一致），分別指定兩位講者要用的聲音，按「🎧 產生對話語音」即可生成整段對話。

這個版本跟「本機版」的差異

這個工具還有一個本機版（需要下載到自己電腦、用 Python 執行）。兩者功能相同，差異在於：

純瀏覽器版（這個網頁）本機版
安裝不需要，打開網址就能用需要下載、安裝 Python
雙人對話句子間停頓沒有（沒有 ffmpeg 可以插入靜音，句子直接銜接）可調整停頓毫秒數
配音方式透過一個輕量代理服務轉發直接連線語音服務

聲音選項

配音使用微軟線上語音服務的制式聲音，共 6 種可選：

聲音特色
男聲・沉穩（台灣）台灣腔，適合正式內容
女聲・親切（台灣）台灣腔，日常對話語氣
女聲・活潑（台灣）台灣腔，語氣輕快
男聲・穩重（中國腔）中國腔，穩重語氣
女聲・溫暖（中國腔）中國腔，溫暖語氣
女聲・俏皮（中國腔）中國腔，語氣俏皮

這些都是制式聲音，不是任何真人的聲音克隆。

為什麼需要一個「代理網址」

線上語音合成服務會檢查連線來源，瀏覽器基於安全設計不允許網頁自訂這個來源標頭，所以網頁沒辦法直接連上去要配音。頁面下方「🔧 語音服務代理網址」已經幫你填好一個公用代理，正常情況下不需要更動。如果公用代理太多人用而變慢或暫時失效，可以展開「🚀 想擁有自己專屬的配音服務？」，跟著步驟免費申請一個只有你自己在用的代理（約 5 分鐘，不需要信用卡）。

上傳文字檔

支援 .txt 純文字檔，會自動偵測編碼（UTF-8 或 Big5／cp950 皆可正確讀取中文），不需要自己先轉檔。

語音轉文字

切到「📝 語音轉文字」分頁，選好辨識語言（中文台灣／中文中國／英文），按「🎤 開始錄音」並允許麥克風權限，對著麥克風說話即會即時轉成文字，累加顯示在下方文字框；按「⏹ 停止錄音」結束。文字結果可以直接編輯修正，也可以「📋 複製文字」或「⬇️ 下載 .txt」存檔，或按「🗑 清空」重新開始。

只支援即時錄音，不支援上傳已錄好的音檔轉文字——這是瀏覽器語音辨識功能本身的限制，沒有官方方式可以把音檔餵給它辨識，只能對著麥克風即時說話。如果需要把既有音檔轉成文字稿，目前這個工具無法做到。

這個功能使用瀏覽器內建的語音辨識，建議用 Chrome 或 Edge，Firefox／Safari 大多不支援，開啟後會直接提示不支援。辨識是把錄音送到瀏覽器廠商（如 Google）的雲端伺服器處理，需要網路連線，跟語音生成功能使用的服務是各自獨立的兩件事。

常見問題

Q：生成失敗，顯示連線錯誤怎麼辦？
請確認網路連線正常；若持續失敗，可能是公用代理暫時人多壅塞，可以稍後重試，或依「🚀 想擁有自己專屬的配音服務？」申請一個自己專用的代理。

Q：雙人對話一直顯示「偵測到 N 位講者」不是 2 位怎麼辦？
請檢查每一行講者名稱拼寫是否完全一致（例如不要有時寫「甲」有時寫「Ａ」），且每行都要用全形或半形冒號分隔講者與內容。

Q：我可以自己架設代理嗎？資料會不會被存起來？
可以，見上方「為什麼需要一個代理網址」。代理程式碼（worker.js）只會把文字轉送給語音服務、取得音訊後原封不動回傳，不會儲存任何內容，程式碼公開在這個工具的 GitHub repo 裡可以自行檢視。

隱私與使用限制

  • 輸入的文字只會經由代理送到微軟線上語音服務做語音合成，代理本身不儲存任何內容。
  • 語音轉文字會把錄音送到瀏覽器廠商的線上辨識服務（例如 Chrome 送到 Google 伺服器），本工具不會另外儲存錄音或文字內容。
  • 生成的音檔與文字稿只存在你瀏覽器的記憶體裡（下載後才會存到你的裝置），重新整理頁面就會消失。
  • 請勿用來生成足以誤導他人、冒充真實人物、或用於詐騙的內容。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
